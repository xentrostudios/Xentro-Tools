AFTER EFFECTS

After Effects Guide

Method 1 (Expression): Alt+Click the stopwatch on Position, Scale, or Opacity & press Ctrl+V.

Method 2 (Keyframe Velocity): Select keyframes → press Ctrl+Shift+K → punch in Outgoing & Incoming Influence %.

DAVINCI RESOLVE

DaVinci Resolve Guide

Edit Page (Spline): Click the wavy spline icon on timeline clip → select keyframes → press T → punch in Start & End Ease %.

Fusion Page: Open the Spline editor, select keyframes, and type ease percentages into the top Ease boxes.

PREMIERE & UNIVERSAL

Premiere & Web Guide

Preset (.prfpset): Download preset → In Premiere Effects panel right-click Presets → Import Presets → Drag onto clip.

Velocity Handles: Right-click keyframes → Temporal Interpolation → Ease Out/In → Drag handles to match preview curve.

CSS / Web: Copy cubic-bezier value directly into Webflow, Framer, or stylesheets.
